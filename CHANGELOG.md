# Changelog

All notable changes to `filament-masonry` will be documented in this file.

## 1.0.0 - 2026-10-19

- Automatic masonry for grids of two or three columns that only contain sections
- `FilamentMasonryPlugin` with `auto()`, `breakpoint()` and `gap()`
- `Masonry` component and `Grid::masonry()` macro
- Native masonry (`display: grid-lanes`) where the browser supports it
- Filament 4 and 5
